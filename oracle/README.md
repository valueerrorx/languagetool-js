# Oracle

Spec: docs/ORACLE.md. Commands: `npm run oracle -- <ID> [<case>] | --all | --selftest`, `npm run parity [-- <ID>...]`.

- Pinned env: env -i, PATH=/usr/bin:/bin, HOME=<work>/home, LANG=LC_ALL=C.UTF-8, TZ=Europe/Vienna, JDK 17 (/usr/lib/jvm/java-17-openjdk), -Duser.language=en -Duser.country=US -Dfile.encoding=UTF-8, tmpdir=<work>/tmp.
- Fixed clock: libfaketime v0.9.13 (oracle/scripts/build-faketime.sh -> oracle/tools/, gitignored), start-at 2026-03-15 10:00:00 Europe/Vienna. `--selftest` checks it.
- Harness: oracle/harness/src (build: oracle/scripts/build-harness.sh), JSON-lines protocol `{id,op,args}` -> `{id,ok,result|error}`. Ops: probe, X-LANGUAGES, num-tostring, unicode-dump, locale-dump (plus probe-*). Clock values in probe are truncated to the minute.
- Cases: oracle/cases/<ID>/<case>.json (harness kind only so far). Fixtures: tests/golden/<ID>/<case>/.
- JS twins: oracle/adapters/<op>.mjs exporting `run(args)`; `export const notPorted = true` marks a stub (reported "NOT PORTED", not a failure). An adapter may also throw an error with `notPorted === true` to mark a single request NOT PORTED; such requests are dropped from the comparison, the remaining ones are compared, and a case with no mismatches but some notPorted requests is reported NOT PORTED. Ops without an adapter that Harness.java does not know are answered with its `java.lang.IllegalArgumentException: unknown op: <op>` envelope and compared. Error envelopes use `javaClass` (FQCN) when present, else constructor.name, for the error and its causes.
- Pseudo-IDs: X-SELFTEST (probe), X-LANGUAGES, X-NUMFMT (Double/Float.toString; no inventory ID owns it, it is a lib helper in toString.js).
- Probe topics (S01/S05/S11/S19): ops probe-numbers/-strings/-format/-collections (Probe*.java), case generators oracle/scripts/gen-probe-cases-*.mjs write oracle/cases/X-PROBE-*/ (inputs only). Numbers travel as {t,v} strings; probe responses are ASCII-escaped JSON so lone surrogates survive; strings are returned with their UTF-16 `units`.
- X-UNICODE / X-LOCALE (S07): ops unicode-dump (parts props, case, strcase, strctx, normalizer, pattern; flat RLE triples [start,len,value]; ASCII-escaped output) and locale-dump (UnicodeDump.java, LocaleDump.java); generator oracle/scripts/gen-cases-unicode-locale.mjs. Pattern classes dumped: posix, java*, general categories, binary Is* props, some scripts (IsLatin, IsGreek, ...), In* blocks, UNICODE_CHARACTER_CLASS variants, \w\d\s\h\v\R, CASE_INSENSITIVE(+UNICODE_CASE) single chars; IsEmoji is unsupported in JDK 17 (recorded as error). Collator is not used by LT sources, so not dumped. Locale specs: `new:en-US` = malformed `new Locale("en-US")`.

## Content oracle (F03, docs/ORACLE.md)
- Harness ops (ContentOps.java): `check` {lang,text,enabledRules,disabledRules,enabledCategories,disabledCategories,enabledOnly,enableTempOff,level,mode,paraMode,tokenizeText,toneTags,motherTongue,fresh} -> {matches[],sentenceRanges,extendedSentenceRanges,ignoredRanges}; `analyze` {lang,text,preDisambiguation,...} -> sentences/tokens (readings, chunk tags, flags; positions sentence-local, `offset` = sentence start); `rules-list` {lang}; `rule-examples` {lang,ruleIds?,offset,limit,unrestricted} (offset/limit count rules; per example `restricted` = only that rule via RuleSet.plain at level PICKY, `unrestricted` = full check); `disambiguation-examples` {lang(short code),offset,limit} (mirrors DisambiguationRuleTest: actualInput/actual per marker token, `touched` for untouched examples). JLanguageTool instances are cached per (lang, motherTongue, rule selection) inside one JVM; `fresh:true` bypasses. Unknown language -> error envelope.
- Case kinds: `harness`, `cli` {args,stdin,files,env,jar} -> stdout.txt, stderr.txt, exit.txt, files.json (created/changed files in the work dir); `http` {serverArgs,requests[{method,path,params,body,contentType,headers}]} -> responses.json [{status,contentType,accessControlAllowOrigin,body}]. One HTTPServer JVM per run and distinct serverArgs, free port, started from $LT, fixed clock, killed at exit. Requests via Node fetch; POST params as form body.
- Comparators (oracle/comparators): `check`, `analyze`, `rule-examples`, `disambiguation-examples`, `rules-list` (harness envelopes), `api`, `cli` (result objects), shared deep.mjs (key order ignored, integers exact, floats via Math.fround, missing vs present keys differ). `software.version/buildDate/commit` ignored in api (D-023). analyze does not compare historicalAnnotations (Java diagnostic).
- Normalisers (oracle/lib/normalizers.mjs): paths (always), stackFrames, buildDate, commit, durations. Case files list them in `normalize`.
- JS adapters for cli/http: oracle/adapters/cli.mjs and http.mjs (`run(cs,{workDir})`, currently notPorted stubs). Harness ops without adapter file are NOT PORTED.
- Corpus: oracle/scripts/fetch-corpus.mjs (public-domain Gutenberg, oracle/corpus/<de|en|fr>/corpus.txt + SOURCE.md); oracle/scripts/gen-corpus.mjs --lang --code --id [--dry] writes chunked case files (rule-examples, disambiguation-examples, corpus-check, corpus-check-picky, corpus-http). oracle/scripts/gen-oracle-check.mjs writes X-ORACLE-CHECK (sample proof, 14 cases). Unit tests: tests/oracle/comparators.test.js.

## Regex oracle (F04, X-REGEX)
- Harness ops (RegexOps.java): `regex` {pattern, flags(int), inputs[], limits[] (split), ops[] (matches, lookingAt, find, split, replaceAll, replaceFirst), replacement?} -> {compile:{groupCount,flags} | compile:{error:{class,description,index,pattern,message}}, replacement, results[] per input: matches, lookingAt, find [[start,end,[g1s,g1e,...|null]]], split {limit: [..]}, replaceAll, replaceFirst}; per-op failures are `{error:{class,message}}` (IllegalArgumentException/IndexOutOfBounds for bad replacements). Matching runs on a step-budgeted CharSequence (3M charAt calls, deterministic) so catastrophic patterns end as `IllegalStateException: StepBudgetExceeded` (none occurred). `regex-harvest` {lang} walks all rules of a loaded language (see below).
- Harvest: `node oracle/scripts/harvest-regex.mjs` -> oracle/cases/X-REGEX/harvest/{patterns,report,dynamic-sites}.json. Runtime walk over 13 de/en/fr variants with a trace shim (oracle/scripts/build-trace-shim.sh generates a copy of StringMatcher with a hook into oracle/harness/shim-src, compiled to build-shim, put in front of the classpath for harvest only; the original is untouched) because StringMatcher replaces single-literal regexes by the literal. Static: Java literals/helpers (lib-java-literals.mjs), filter args in rule XML, wrongWordInContext.txt, ProhibitedCompoundRule.blacklistRegex.
- Cases: `node oracle/scripts/gen-cases-regex.mjs` (inputs only): `shallow-NNN` (every distinct (pattern, flags): compile result + <=3 inputs: matches/lookingAt/find), `deep-NN` (construct sample, ~40 inputs, all ops, split limits 0,-1,2,1), `synthetic-NN` (hand-picked constructs from SEMANTICS S2: properties, classes, inline flags, CI, escapes, errors, replacement syntax). `node oracle/scripts/regex-constructs-report.mjs` writes oracle/cases/X-REGEX/CONSTRUCTS.md.
- Regenerate with `npm run oracle -- X-REGEX` (all cases of the ID). Careful: `--all` regenerates every ID.

## Check-pipeline oracle (F15, X-CHECK-PIPE)
