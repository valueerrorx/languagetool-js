## Ops (MetaOps.java; ASCII-escaped JSON)
- `lang-priority {lang, ids?:[..], rules?:[{ruleId,subId?,category?:{id,name?},issueType?,tags?,priority?}], real?:true}` -> `{ids:[[id, int|{error}]], rules:[{id,subId,issueType,categoryId,categoryName,tags,priority,rulePriority}], realRules:[[fullId,categoryId,issueType,ownPriority,rulePriority]]}`. ids use the protected getPriorityForId via reflection. `real` = new JLanguageTool(lang).getAllRules() (only for de-DE, de-AT, de-CH, en-US, en-GB, fr, fr-CA to stay below 10 MB).
- `lang-filter {lang, cases:[{name, fn: filter|afterOverlapping|adjustFrench, text, enabledRules?, matches:[{ruleId, subId?, ruleKey?, category?, issueType?, tags?, priority?, from, to, sentPos?, message, shortMessage?, suggestions?:[str|{replacement,shortDescription,suffix}], specificRuleId?, errorStr?:true|"str", sentence?, noSentence?}]}]}` -> per case `{matches:[full match dump + fullId + originalErrorStr + ruleObject (index of the input Rule instance or -1) + ruleState], rulesAfter:[ruleState per input rule]}` or `{error}`. Matches with equal `ruleKey` (default ruleId|subId) share one Rule object (the filters mutate it: ITS type, category, tags). Sentence = harness-built raw AnalyzedSentence of `text`; sentence positions = from/to unless sentPos. `adjustFrench` only for French variants. Every variant also runs 12 cases of each other family (inherited behaviour, German cases on en/fr etc.).
- `lang-typo {lang, strings}` -> toAdvancedTypography each. `lang-statics {calls:[{fn:getInstance|new, className}]}` -> [class, shortCodeWithCountryAndVariant] | {error}; order matters (guards).

## Findings pinned (reproduce)
- German/French filter: period-drop test uses the sentence text, so "Das ist ein Test" + suggestion "Test." is dropped and "Das ist ein Test." kept; sentence==null -> NullPointerException (helpful-NPE text, class compare only); merge of a match without suggestions -> IndexOutOfBoundsException "Index 0 out of bounds for length 0"; merged match keeps the FIRST match's Rule object and rewrites its ITS type for ALL matches sharing that rule; overlapping later match is silently dropped.
- Swiss: `ß`->`ss` applied to ALL suggestions of every surviving match (also non-GGEC ids, also suffix untouched); substring errors for to > length or different sentence propagate as StringIndexOutOfBoundsException.
- English filter: suggestion dedupe uses SuggestedReplacement.equals (shortDescription/suffix count); the copy via `new RuleMatch(rm, repl)` keeps specificRuleId; EN_SIMPLE_REPLACE*GRAMME(S) sets LocaleViolation on the shared Rule (affects the other matches of that rule instance).
- French adjust: casing check uses equalsIgnoreCase (also identical text, İ/ß cases pinned), ORTHOGRAPHY->CASING replaces ALL occurrences; APOS_TYP only touches suggestions longer than 1 char.
- statics: NonSwissGerman `new` -> java.lang.InstantiationException (message null); AmericanEnglish/BritishEnglish/CanadianEnglish/French/CanadianFrench/SwissFrench/BelgianFrench second instantiation -> "Language was already instantiated ...".
