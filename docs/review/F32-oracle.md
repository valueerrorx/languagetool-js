Ops:
- disamb-run {lang, global?, xml?, texts:[string|{syn:[{readings:[[token,lemma,pos]],ws}]}], jobs:[{rule:int|null, digest?, texts:[i]}]} -> {jobs:[[per text]]}. rule null = XmlRuleDisambiguator (xml = inline disambiguation file served through an overridden loadPatternRules, global files still real) and mirrors JLanguageTool#getAnalyzedSentence minus post chunker: preDisambig = AnalyzedSentence.copyReadings(raw.getTokens()) BEFORE disambiguate, result = new AnalyzedSentence(disamb.getTokens(), pre). rule int = DisambiguationPatternRule#replace alone on a fresh raw sentence (index into the inline list or the language disambiguation.xml list as UnifyOps.disambRules loads it); {same:bool (result==input), s (only when changed)}. digest:true -> {n, ch (p!=null), dg2 = sha1(canon(dump))}. Fresh sentence per (job,text) because ADD mutates readings in place. Errors: {error:{class,message(NPE=null),causes[{class,message}]}} per job-entry (load errors appear as the job's single entry).
- Sentence dump: {t: all tokens (getTokens), p: null | {d:[[i,tok]..]} (preDisambig tokens differing from t, same length) | {full:[tok..]}, w: getOriginalPosition(i) for i in non-whitespace tokens, pw: pre non-whitespace count, pos: sorted getPosTagSet, lem: sorted getLemmaSet, dg: sha1(AnalyzedSentence#toString())}. tok = [text,startPos,endPos,posFix,cleanToken,whitespaceBefore,flags,readings,chunkTags]; flags bits 1 immunized,2 ignoredBySpeller,4 sentStart,8 sentEnd,16 paraEnd,32 whitespace,64 linebreak,128 tagged,256 typographicApostrophe,512 isWhitespaceBefore; reading = [token,lemma,pos(,rflags)] with rflags 1 = AnalyzedToken#isWhitespaceBefore, 2 = hasNoTag (only when non-zero). canon(): strings as UTF-16 code unit lists, lists "[a,b,]", maps "{k=v|}", null "N" (JS twin in _disamb-common.mjs; verified against 138 unchanged corpus sentences).
- disamb-examples {lang, xml?, offset, limit} -> {total, rules:[{i,id,subId,untouched:[{blank,eq,dg}],examples:[{exp,noIn,noOut,same,eqClean,eqSent,inPos,inRaw,inA,outPos,outRaw,outA,inDg,outDg}]}]}: DisambiguationRuleTest per rule with disambiguateUntil cascade (rules before the first rule of the same id), WITHOUT lang.getDisambiguator().preDisambiguate; assert conditions of the Java test are recorded as booleans instead of failing (en: 458/463 inputs, 395/463 outputs equal the XML's own expectations; the rest need the EnglishHybridDisambiguator multiword preDisambiguate, F45). inA/outA use sortForms (Java String#split(",") semantics, Arrays.sort).
- rule-match-disamb {lang, global?, dxml?, xml?, texts, jobs:[{src:{file,rule}|{rule}, texts}]} -> {texts:[[nonWsTokens, sha1(toString)]|null], jobs:[[{raw,nulls,kept,sugMatches,full:[RuleMatch dump]}|{error}]]}: as rule-match (F29 dumps) but on XML-disambiguated sentences (dxml = inline disambiguation file) plus `full` = PatternRule#match(sentence) (antipattern immunization re-run via DisambiguationPatternRule#replace, RuleWithMaxFilter). The disambiguated sentence is reused across jobs.
