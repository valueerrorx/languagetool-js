## Ops (oracle/harness/src/ltjs/oracle/FilterOps.java)
- filter-cfg {name,cfg}: registers a named configuration of the case file (requests refer to it as filter.cfgRef). Adapter: filter-cfg.mjs writes into CFG of _filters-common.mjs (reset by filter-run beginCase).
- filter-run {lang, text:string|{syn}, filter:{cls}|{test,cfgRef}, args:[[k,v|null]], from,to, message?, shortMessage?, suggestions?, patternTokenPos, tokenPositions, window?[a,b), setOriginal?(default true), dumpTokens?, clockAt (JS clock)} -> {tokens?, result: null | {same:true} | {same:false,dump} | {error:{class,message,causes}}, inAfter?: dump of the INPUT match when the filter mutated it}.
  Setup: rule = inline PatternRule FILTER_RULE in `lang` (getFullId "FILTER_RULE[1]"), sentence = raw tagger sentence (NOOP chunker) like X-RULEINFRA, patternTokens = getTokensWithoutWhitespace() (index 0 = SENT_START) sliced by `window`, match = new RuleMatch(rule, sentence, from, to, message, shortMessage) + setSuggestedReplacements + setOriginalErrorStr() (as PatternRuleMatcher#createRuleMatch does).
  filter.cls -> RuleFilterCreator.getInstance().getFilter(cls) (singleton cache, ClassNotFound/Instantiation texts, e.g. abstract class -> "Could not create filter class using constructor ..." + InstantiationException). filter.test -> test subclass of the ABSTRACT class (the abstract classes cannot be instantiated; language subclasses are later steps), configured by cfg:
  - datecheck / datecheck-sugg / future / newyear: cfg {locale (Calendar.getInstance(Locale)), trim, dayPrefix[[prefix,calDay]], monthPrefix[[prefix,month]], dayNames[7 Sun..Sat], dayWords[], wrongYear, adjust:"de", dayStrLike:"en"} = tables of the de/en/fr DateFilterHelper (getDayOfWeek(String)=first startsWith prefix after trimSpecialCharacters+lowercase else RuntimeException "Could not find day of week for '<s>'", getMonth likewise "Could not find month '<s>'", getDayOfWeek(Calendar)=dayNames[DAY_OF_WEEK-1], getDayOfMonth(String)=index in dayWords or 0).
  - partialpos: cfg.mode demo (DemoPartialPosTagFilter) | tagger (language tagger, raw) | disamb (tagger + language disambiguator).
  - findsugg: AbstractFindSuggestionsFilter with STUB speller cfg.spell {token:[suggestions]}, getTagger=language tagger, cfg.synth -> language synthesizer, excRegex (isSuggestionException by token), clean (cleanSuggestion removes "-"), pre (preProcessWrongWord upper-cases).
  - advsynth (excRegex -> isSuggestionException(token), newLemma:true -> getNewLemma = word+newLemma.substring(1) else null), suppress (no hooks), numberinword (cfg.misspelled[], cfg.spell{}), contractions (cfg.pairs replace), texttonumber (English number words incl. half/tenth/hundredth/big=16777217f/quadrillion=1e20f; isComma "," or "point"; isPercentage "%" or "percent"; cfg.brackets formatResult, cfg.splitDash tokenize), sentencecase (cfg.exceptions -> tokenIsException).

## Port contract (adapters call the real port; nothing hardcoded)
- Concrete classes are looked up with ClassBroker.hasClass(fqcn) + RuleFilterCreator (missing -> request notPorted). Abstract bases: ClassBroker.forName('org.languagetool.rules.Abstract...') must return a non-JAVA_PENDING class; the adapter subclasses it with the Java hook names (getCalendar, getDayOfWeek, getDayOfMonth, getMonth, getErrorMessageWrongYear, getDayStrLikeOriginal, adjustSuggestion, tag, getTagger, getSpellingSuggestions, getSynthesizer, isSuggestionException, cleanSuggestion, preProcessWrongWord, getNewLemma, isMisspelled, getSuggestions(String), fixContractions, isComma, isPercentage, formatResult, tokenize, tokenIsException). OVERLOAD RULE: Java overloads getDayOfWeek(String)/getDayOfWeek(Calendar) are ONE JS method dispatching on typeof (the adapter overrides exactly that); getSuggestions in AbstractNumberInWordFilter takes the word. If the port names hooks differently, adjust oracle/adapters/filter-run.mjs (subclass bodies are only exercised once the port exists; plumbing was verified with a stand-in AbstractMakeContractionsFilter: 12/12 requests equal).
- AbstractTextToNumberFilter: the adapter expects protected statics `numbers`/`multipliers` on the abstract class as JavaHashMap (put/containsKey) holding Math.fround values (Java Float).
- Date filters need src/lib/java/Calendar.js: `Calendar.getInstance(Locale)` (constructor `new Locale(lang,country)`), non-lenient GregorianCalendar (Julian/Gregorian cutover 1582, year 1..292278994, get() throwing IllegalArgumentException for invalid fields), set(y,m,d,h,mi,s) keeping milliseconds of "now", get(DAY_OF_WEEK/YEAR/MONTH), after(), Calendar.SUNDAY..; AbstractFutureDateFilter compares fresh calendars with ms, so `dateFromDate.after(currentDate)` depends on the ms of the clock (cases avoid the same-day edge being ms-sensitive: dates are whole days away or the same day 00:00 vs 10:00/12:00).
- Clock: Java runs under libfaketime; the adapter sets process.env.LTJS_FIXED_TIME per request (`clockAt`, default 2026-03-15T10:00:00+01:00) BEFORE the filter runs, so src/lib/java/clock.js (const read at import) must read the env lazily (or expose a setter) for the January/leap/December cases; TZ must be Europe/Vienna (set in the parity process, as for cli/http). TestHackHelper.isJUnitTest() is false in the oracle (no 2014 hack), port must not apply it.
- Java logs "Skipping potential match for <fullId>" (stderr, warn) for runtime errors in AbstractDateCheckFilter; not compared.
