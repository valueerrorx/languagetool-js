## Ops (ASCII-escaped JSON)
`lang-detect {calls:[{fn,...}]}` -> one result or `{error:{class,message}}` per call:
- `clean {text,maxLength}` -> string (cleanAndShortenText of a DefaultLanguageIdentifier(maxLength), real ctor via reflection; maxLength<10 -> IllegalArgumentException "maxLength must be >= 10 (but values > 100 are recommended): N"). `construct {maxLength}` -> "ok" | error.
- `detect {text,maxLength?=1000,noop?,preferred?,force?,clean?=true}` -> `{clean, result}`; force absent/null = 3-arg overload detectLanguage(text,noop,preferred), else 4-arg. `result` = null (Java null) or `{given, detected:{code (getShortCodeWithCountryAndVariant), shortCode, name (getName, as RuleMatchesAsJsonSerializer.writeLanguageSection writes detectedLanguage.name/code), class, spellcheckOnly, defaultVariant}, confidence (float), confidenceBits (Float.floatToRawIntBits), source}`. `detect1` = detectLanguage(String) -> language or null.
- `scores {text,count,noop?,preferred?,force?}` -> list of the same result objects (getDetectedLanguageScores; count>1 rounds to 2 decimals as float).
- `server {text,fallback?,variants,noop,preferred,force}` -> result object of the REAL `V2TextChecker#detectLanguageOfString` (package-private, via reflection on a real V2TextChecker built from `new HTTPServerConfig(new String[0])`): cleanAndShorten + detectLanguage + fallback language + default-variant / preferredVariants mapping + BadRequestException texts. This is the call TextChecker makes for explicit-language AND auto requests (V2TextChecker.getLanguage:120; explicit language only changes givenLang), so explicit-language requests are mirrored with the same args; `given` is always null here.
- `unicode {text,maxCheckLength?}` -> dominant codes list. `common {text}` -> `[[langCode,count],...]` sorted by code (CommonWordsDetector over all modules; HashMap order not pinned).
- `svc {steps:[{fn: clear{type}|getDefault{maxLength}|getInitialized|canDetect{code,additional}|langForShortCode{code,additional}}]}` on LanguageIdentifierService.INSTANCE (getDefault reports class, sameAsBefore = same object as the previous getDefault, and a clean-length probe of 1200 x chars = effective maxLength).
`lang-detect-resources {}` -> every language: code, class, commonWordsPath/exists/bytes/sha256/entries; optimaize profileCodes, per-code resource + bytes + sha256; external profiles eo/crh.
