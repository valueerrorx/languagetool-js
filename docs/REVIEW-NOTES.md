# Review Notes

- Boxed numbers: JS number stands for Java Integer/Long/Double; Objects.equals on numbers = Object.is (matches Double.equals NaN/-0, identical for ints); -0 always prints "-0.0"; route String.valueOf/equals/hash through one shared helper (Objects.js).
- Do not drop Java precondition checks in ported JDK methods (e.g. Throwable#initCause self-causation/overwrite).
- Keep typed overloads distinct (Object vs String vs Throwable constructor forms), e.g. AssertionError(Object) -> String.valueOf + initCause.
- "Verify via oracle" items need a fixture before merge; never ship from memory.
- Comments: one line only, also file headers.
- Oracle adapters must reproduce Harness.java error paths for malformed input.
- int helpers must never return -0 (use `| 0`); adapters/tests compare with Object.is so -0 is not hidden by printing.
- JDK overload sets: pick JS variant by Java static type (P15); NPE texts per entry point (P15).
- D-042: do not reject idiomatic JS solutions that are fixture-verified identical; reject only observable divergence or unverified claims.
- D-043: block only divergences reachable from API/CLI output or degrading results; log unreachable JDK edge cases in docs/review/unreachable.md.
- Adapters must call the port; never hardcode Java expected values. Missing dependency -> throw notPorted for that request.
- Orphan golden dirs (no matching oracle/cases/<ID>/<case>.json) must be deleted when a generator drops cases; check before blaming stale fixtures.
- A class pulled forward from a later step comes with its Java test class ported in the same step.
- Interim guards/stubs need a removal note in docs/PLAN.md (target step), not only a code comment.
- Java `substring`/`charAt`/`subList`/array index with computed bounds: use the throwing helpers in src/lib/java/ (JS clamps or yields undefined/TypeError, Java throws StringIndexOutOfBounds/ArrayIndexOutOfBounds).
- Guava/JDK collection sizing: take formulas from the pinned jar (javap), never from memory; iteration order depends on it.
- No "same behaviour as Java" claim on a stub/fallback without an oracle check; otherwise mark it unverified.
- JDK/library semantics in a src/lib/java helper must be verified against the pinned JDK 17 / jar (probe or javap), not written from memory.
- A code comment citing unreachable.md requires the matching entry there in the same step.
- JDK library behaviour without src.zip: read `javap -p -c --module java.base <class>` of the pinned JDK 17 and verify the port with a random differential corpus against the JVM (see tests/lib/java/URL.test.js, JavaConcurrentHashMap.test.js).
- .gitignore entries must be anchored (`/resources/`), otherwise source/test/golden directories named `resources` are silently untracked.
- Adapters must not fake a class whose constructor is notPorted (no `Object.create(JLanguageTool.prototype)`); let notPorted propagate.
- No local copies of src/lib/java helpers (e.g. listGet); import the shared one.
- Java string semantics (javaSplit, Java regex) apply also in test code that mirrors Java test helpers.
- Status verified only when every class named in the inventory row exists in src/ and is exercised by a fixture or test.
- A "PASS (partial: N notPorted)" is not done: a step whose PLAN note names a fixture must bring its partial count to 0.
- Set status ported only when every Java class of the ID exists in src/ (F35: CORE-0186).
